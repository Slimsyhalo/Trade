# Binance QuantLab

Reproducible Binance USD-M Futures data foundation for BTCUSDT, ETHUSDT and SOLUSDT.

Historical window: 2024-10-07 through 2026-10-07 UTC. Read-only market research; no orders or strategy optimization.

Pilot implementation and data exist locally. Remote dataset publication and restore verification are pending. Do not assume data exists unless listed in the catalog.
