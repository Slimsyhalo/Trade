# Original official-release provenance

Actual acquisition discovered and preserved 109 official HTML release documents
in the requested publication-date window: 23 CPI, 23 PPI, 23 employment, 23 JOLTS
and 17 Federal Reserve documents. The Fed set includes a policy-framework notice;
17 documents must not be described as 17 policy meetings. Current indexes
discover historical archive URLs; they do not establish historical calendar
versions, full event-universe completeness or an invariant monthly schedule.

Original HTTP response bytes are compressed without modification, identified by
original-content SHA-256 and compressed-asset SHA-256. Parsed metadata checks
the date against the source URL and derives UTC using America/New_York and
historical daylight saving rules. A publisher's explicit EST/EDT label must agree
with that date. JOLTS uses a release header distinct from the embargo wording
of other BLS releases. Both source formats are tested; failed original attempts
are retained and the successful retry reuses prior acquisitions.

Every record separates the publication claim, original zone/label, acquisition
time, current observed availability, source headers and historical effective
availability. Current archived HTML can include later template changes or
corrections. Its original historical version/dissemination time is not proved
by downloading it now. Historical effective availability therefore remains null,
revision lineage remains unestablished and strict historical replay is blocked.
No current revised database values have been substituted, and numeric release
values are not yet certified/extracted in this metadata stage.

The isolated workflow materializes the exact recorded version (or stops if it
changed), publishes original compressed HTML and metadata with full readback,
restores one original per source category, records durable Git receipts and
only then prunes originals. Archive discovery pages are also preserved remotely.
Paid source licenses and article republication rights are not assumed.

Remaining C19 scope includes original-value/vintage reconciliation, calendar
revisions, minutes/SEP, ECB, regulatory/Binance/incident event acquisition and
scoped news metadata. The 109-document set is an evidence checkpoint rather than
full C19 acceptance. Structured sources/limitations live in the source inventory.
