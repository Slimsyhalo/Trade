# Live continuity finding and bounded batching probe

All 227 preserved original segments / 6,578,897 rows were read completely against immutable completed recovery head `455e0cc4880b42329169d7c569dffbe4adb9fb61`. Local original artifact inspection is distinct from a fresh download of every remote asset. No original file, QA decision or acquisition manifest was changed.

The public route contains 197 connection starts, 196 disconnects and 588 depth sequence gaps. Independent sequence analysis reproduces all 588 stored gap markers. Disconnect errors: 186 `no close frame received or sent`; 10 `sent 1011 (internal error) keepalive ping timeout; no close frame received`. The market route contains one connection and no observed aggregate-ID gaps. All routes show no recorded receive-clock regression. Snapshot route contains one HTTP451 unavailability marker; no usable depth snapshot is established. Full L2 and continuous service remain uncertified.

These errors do not establish a unique root cause. Source disconnects, transport behavior, consumer load and heartbeat starvation require a controlled operational observation. Original spool code scans disk usage and flushes compression for every message, imposing avoidable synchronous work. Persistence now uses bounded batches, fast gzip and one disk-budget scan/flush per batch. Actual application consume timestamps and per-row sequence cursor snapshots survive rotation. Raw duplicate messages and gaps remain preserved. Failed batch persistence stops the capture; unconfirmed row count is exposed and ambiguous writes are never replayed automatically.

Buffers are limited to 128 records and a conservative 4 MB encoded estimate; Sink rejects batches beyond 256 records / 4 MB. Flush is triggered by arrival count, arrival-driven 100 ms elapsed check and every disconnect/stop/finally. This is not a strict idle-time durability deadline: an idle partial buffer persists on the next event or connection termination. Buffered rows are volatile until persisted; a process kill can lose that bounded tail. Existing open segment crash/quarantine policy is unchanged. Shared 2 GB disk Budget remains authoritative and reserves conservative compressor/manifest overhead. This optimization does not certify source completeness, calibrated latency or permanent service.

A local persistence-only replay of 10,000 actual captured payloads retained exact payload order/content in both implementations. Original elapsed 0.671 s; batched elapsed 0.102 s (6.60x speed ratio), for one workload. Receipt timestamps differ by benchmark policy and gzip bytes differ; this is not network throughput or continuity evidence. Temporary benchmark copies were removed.

213 tests passed locally, including original collector recovery tests, cursor preservation across intra-batch rotations, whole-batch validation before writing, budget scans, fail-closed ambiguous write behavior and isolated Release tag validation.
